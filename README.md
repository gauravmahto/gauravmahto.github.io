## ✨ Quick Start

1. Clone the repository.
2. Create and activate a Python virtual environment.

   **Windows:**

   ```cmd
   python -m venv venv
   venv\Scripts\activate
   ```

   **macOS/Linux:**

   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

3. Install the requirements:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the local development server:

   ```bash
   mkdocs serve
   ```

5. Open [http://127.0.0.1:8000/](http://127.0.0.1:8000/).

---

## 📦 Requirements

The portfolio uses [MkDocs](https://www.mkdocs.org/) with the [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) theme. The pinned runtime dependencies are listed in `requirements.txt`; a Conda environment definition is also available in `environment.yml`.

Install the site dependencies with:

```bash
pip install -r requirements.txt
```

> **Tip:** Use a clean virtual environment to avoid dependency conflicts.

The broader scientific and data environment is captured in `environment.yml`. Packages from that environment are used for project work but are not required to build the MkDocs portfolio.

Validate a production build with:

```bash
mkdocs build --strict
```

Deploy to GitHub Pages with:

```bash
mkdocs gh-deploy
```
